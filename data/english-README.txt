At runtime ibus-libime uses only ASCII alphabetic entries, indexing by
lowercase spelling while preserving the original display/commit casing.
The data file is not modified, and no upstream code is included.

english-technical.txt is a separate, project-maintained supplement of
canonical technical names, distributed under the project's GPL-3.0 license.
It is not copied from FrequencyWords or another input method's dictionary.
Supplemental words inherit the base word's frequency (zero if absent);
canonical spellings take precedence on equal frequency without removing
lowercase variants.
